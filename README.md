# ZPSB Lab

## Courses

- [Sztuczna Inteligencja - Informatyka](ai/)

## Setup

Clone repository in the terminal

```sh
git clone git@github.com:wnowicki/zpsb.git
```

### Python

- Install UV
  - Execute firs command from [UV Installation](https://docs.astral.sh/uv/getting-started/installation/)
  - Probably you need to restart your terminal
- Enter project directory `cd zpsb-lab`
- Create Python Virtual Environment for the project

```sh
uv sync
```

- Open project in Visual Studio Code
  - Allow installation of Python extension (if you don't have it yet)
  - In case of Jupyter, select project environment, the one starting with `.venv`
